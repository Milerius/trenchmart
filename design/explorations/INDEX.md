One line per artifact: file — what it shows — question for the owner.

- `03-landing-concept.png` (+ `.html`) — Landing concept (desktop 1440 + phone 390): devnet bar, AI-verification trust strip, 'How buying works' strip, exact fee example table for every tier, corrected card pricing. Q: show live stats (verified listings, SOL in escrow, refunds) once real data exists?
- `04-marketplace-concept.png` (+ `.html`) — Marketplace/browse concept: terminal pills, category + trust filters, cards priced at the user's tier (Trencher), mobile filter sheet, plus loading skeleton, empty, API error, holder-only lock, in-review and logged-out card states. Q: show 'In AI review' listings to buyers (not buyable) or hide them until live?
- `05-listing-detail-concept.png` (+ `.html`) — Listing detail concept: Security report tab first (AI attestation by trenchmart-ai-v1), receipt buy box with 'your tier' vs 'preview' pills, network fee shown apart, mobile sticky buy bar, buy box states (logged out / owned in escrow / holder-only lock). Q: show 'Disputes lost 0 of 1,204' (total sales) publicly, or as a rate?
- `06-checkout-fee-breakdown-concept.png` (+ `.html`) — Checkout sequence: connect (SIWS, 'not a transaction'), review receipt (exact fee, tier discount, network fee apart, vault, memo, balance check, 20-min quote), approve in wallet (what the wallet should show), confirming (commitment steps + server check), paid/in escrow, and errors (wallet cancel = neutral, not enough SOL, quote expired, tx failed). Q: show fiat (≈ $) on mainnet?
- `07-escrow-status-concept.png` (+ `.html`) — Escrow status concept: My purchases table (in escrow / disputed / released / refunded), order timeline with countdown bar and UTC times, receipt, disputed state with both outcomes, phone cards, dispute form, creator payout view. Q: allow download during escrow (download-then-dispute risk), or wait?
- `08-dashboard-concept.png` (+ `.html`) — Creator dashboard concept: 'needs your note' banner, earned / in escrow / next payout / disputes tiles, listings table with 5-step pipeline (incl. AI verification) and status tags, payout batches with multisig state, trust requirements, AI-verification explainer, phone + first-visit empty state. Q: can creators appeal an AI rejection to a person?
- `03-landing-concept-v2.png` (+ `.html`) — v2 with owner decisions: LandingStats (sample mode by default, live mode switches in automatically), 'Preview prices' notice for logged-out visitors, USD next to every SOL amount, AI verification 'in seconds', download unlocks after escrow releases.
